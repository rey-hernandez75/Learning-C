# 005 - Lesson Title 

005_preced_oper_aritm_01
Understanding Arithmetic Operator Precedence in C


## Objective

The objective of this program is to understand how arithmetic operator precedence works in the C programming language.
Through simple examples, the program demonstrates how addition, subtraction, multiplication, and parentheses affect the order in which expressions are evaluated. It also encourages the user to predict the result before executing each expression, reinforcing the learning process.

---

## Topics

- Variables
- Integer data type (`int`)
- Arithmetic operators (`+`, `-`, `*`)
- Operator precedence
- Parentheses in expressions
- Order of evaluation
- User input with `getchar()`
- Output with `printf()`
